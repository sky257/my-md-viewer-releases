# My MD Viewer 0.1.4

설정 변경 결과를 저장 전에 바로 확인할 수 있는 릴리스입니다.

## 변경 사항

- 테마 선택을 설정 창에서 즉시 미리보기
- 한국어·영어 전환을 설정 창과 앱 전체에 즉시 반영
- 넓게 보기 가로 비율 변경을 본문에 즉시 반영
- 목차 깊이 등 나머지 설정도 변경 즉시 미리보기
- `저장`할 때만 변경 내용을 영구 저장
- `취소`, `Esc`, 바깥 클릭, 닫기 버튼 사용 시 설정 창을 열기 전 상태로 복원

## 설치 참고

Windows Authenticode 코드 서명이 없는 개인용 빌드입니다. Windows SmartScreen 경고가 나타나면 다운로드 주소가 이 공개 저장소인지와 `SHA256SUMS.txt`의 파일 해시를 확인하세요.
