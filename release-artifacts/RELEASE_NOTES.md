# My MD Viewer 0.1.5

외부 링크를 열기 전에 사용자의 확인을 받는 보안 업데이트입니다.

## 변경 사항

- `http`, `https`, `mailto` 외부 링크 클릭 시 확인 팝업 표시
- 팝업에 열려는 전체 주소 표시
- `이 문서에서는 항상 외부 링크 열기` 선택 지원
- 문서별 허용 기록을 앱 재실행 후에도 유지
- 설정의 `기록 지우기`로 저장된 외부 링크 허용 기록 철회
- 취소, `Esc`, 팝업 바깥 클릭 시 링크를 열지 않음

## 설치 참고

Windows Authenticode 코드 서명이 없는 개인용 빌드입니다. Windows SmartScreen 경고가 나타나면 다운로드 주소가 이 공개 저장소인지와 `SHA256SUMS.txt`의 파일 해시를 확인하세요.
