# My MD Viewer 0.1.3

넓게 보기의 본문 가로 비율을 원하는 크기로 조절할 수 있는 릴리스입니다.

## 변경 사항

- 기존 `넓게 보기` 버튼과 동작 유지
- 설정에 `넓게 보기 가로 비율` 슬라이더 추가
- 본문 폭을 60–100% 범위에서 5% 단위로 조절
- 100% 설정 시 읽기 영역의 가로 공간 전체 사용
- 선택한 비율을 저장해 다음 실행과 모든 문서 창에 적용
- Node.js 26에서도 안정적으로 동작하도록 테스트 저장소 환경 보강

## 설치 참고

Windows Authenticode 코드 서명이 없는 개인용 빌드입니다. Windows SmartScreen 경고가 나타나면 다운로드 주소가 이 공개 저장소인지와 `SHA256SUMS.txt`의 파일 해시를 확인하세요.
